                          QR codes

                          Passe une note, un lien ou un texte d'un appareil à l'autre.

                          1. Que veux-tu partager ?

                          2. Le contenu

                          La note est écrite dans le QR code : toute personne qui le scanne pourra la lire. Elle n'est publiée nulle part sur Internet.

                          Texte ou lien : quelle différence ?

                          QR code « texte » : le contenu est dans le dessin lui-même. Pas besoin d'Internet pour le lire, mais il est limité à environ 2 000 caractères, et toute personne qui le scanne voit le texte.

                          QR code « lien » : le dessin contient seulement une adresse. Le contenu reste sur la page web, qui doit être accessible à la personne qui scanne.

                          QR code « note » : c'est un lien vers Carnet qui contient aussi le texte de la note. Le téléphone ouvre Carnet et propose d'ajouter la note. Le texte reste dans le QR code : il n'est pas envoyé sur un serveur.

                          3. Ton QR code

                          Choisis ce que tu veux partager : l'aperçu apparaît ici.

                          Pour le lire : ouvre l'appareil photo du téléphone et vise le QR code, puis touche le lien qui apparaît.

                          Recevoir une note

                          1. Sur l'appareil qui a la note : QR codes → Une note.
                          2. Sur ce téléphone : ouvre l'appareil photo et vise le QR code.
                          3. Touche le lien : Carnet s'ouvre et te propose d'ajouter la note.
